# SAINT LOUP — prototype

Prototype responsive du nouveau site saintloup.store : accueil, fiches produit (Moucadou bleu, Moucadou original, Bandou), Savoir-faire, Histoire et Inspiration.

Ouvrir `index.html` dans un navigateur. La navigation se fait par ancres : `#moucadou-bleu`, `#moucadou-original`, `#bandou`, `#savoir-faire`, `#histoire`, `#inspiration`.

Les images de `img/` proviennent de saintloup.store et des visuels de campagne SAINT LOUP.
